# LRP™ Police MDT

بوت Discord عربي لنظام شرطة **LEGACY ROLEPLAY**. يعرض شاشات MDT كصور PNG مصممة خصيصاً بالأسود والأزرق الكهربائي والفضي، بينما تبقى الأزرار والنماذج تفاعلية داخل Discord. جميع الردود التشغيلية خاصة بالعسكري (`ephemeral`).

## المزايا

- لوحة عمليات تعرض العسكري والبلاغات والتعاميم والوحدات والقضايا.
- البحث عن المواطنين والمركبات بالاسم أو الهوية أو اللوحة.
- سجل جنائي دائم مع المخالفات والغرامات والملاحظات.
- إنشاء البلاغات والقضايا والتعاميم من نماذج Discord.
- تسجيل الدخول والخروج من الخدمة وتحديث الوحدة والحالة وطلب الدعم.
- صلاحيات متدرجة مرتبطة بمعرّفات رتب Discord، مع دعم أسماء الرتب العربية كخيار احتياطي.
- تخزين JSON ذري دون الحاجة إلى خدمة قاعدة بيانات خارجية.

## التشغيل

يتطلب Node.js 18 أو أحدث و`pnpm` الخاص بالمستودع.

```bash
pnpm install
pnpm --filter @lrp/mdt-bot... build
cp apps/lrp-mdt-bot/.env.example apps/lrp-mdt-bot/.env
```

صدّر متغيرات ملف `.env` في بيئة الاستضافة، ثم سجّل أمر السيرفر وشغّل البوت:

```bash
pnpm --filter @lrp/mdt-bot register
pnpm --filter @lrp/mdt-bot start
```

يحتاج التطبيق إلى النطاقين `bot` و`applications.commands`، وإلى صلاحيات `View Channels` و`Send Messages` و`Attach Files` في القنوات التي سيُستخدم فيها.

## ربط الرتب

ضع معرّف كل رتبة في المتغير المقابل. يمكن فصل عدة معرّفات بفاصلة:

| المتغير               | مستوى MDT   | الصلاحيات الرئيسية               |
| --------------------- | ----------- | -------------------------------- |
| `LRP_ROLE_CADET`      | متدرب       | البحث ومشاهدة البلاغات والخدمة   |
| `LRP_ROLE_OFFICER`    | شرطي        | المخالفات والتقارير              |
| `LRP_ROLE_SUPERVISOR` | ضابط        | القضايا وتعديل السجلات           |
| `LRP_ROLE_CHIEF`      | مدير الشرطة | إدارة الأفراد والقضايا والتعاميم |
| `LRP_ROLE_COMMAND`    | القيادة     | صلاحيات كاملة                    |

حامل صلاحية Discord الإدارية يحصل تلقائياً على مستوى القيادة. يجب حماية إدارة هذه الرتب داخل Discord لأن البوت يعتمد عليها كمصدر الصلاحية.

## البيانات والتصميم

يُنشئ البوت `data/runtime.json` عند أول تشغيل انطلاقاً من `data/seed.json`. يمكن تغيير المسار عبر `LRP_DATA_FILE`. الملف التشغيلي غير متتبع في Git ويُكتب بوضع صلاحيات `0600`.

لمعاينة أربع شاشات محلياً دون Token:

```bash
pnpm --filter @lrp/mdt-bot demo:render
```

تُحفظ عشر لقطات مرتبة، بدءاً من شاشة `/mdt` وصولاً إلى القضايا والوحدات والصلاحيات، في `apps/lrp-mdt-bot/assets/screenshots/`.
